# 台股市場寬度 × 費波那契獨立回測

此專案獨立於 `my-market-breadth` 監控網站，不會修改其內容。從網站 `index.html` 取得市場寬度及加權指數歷史 OHLC，另外下載 0050 ETF 價格，以訊號隔日成交比較 A／B／C 原始基準與 A2／B2／C2 波段變體。

## 固定網址直接查看回測報告

每次手動回測完成後，GitHub Actions 會更新 `docs/index.html`、互動圖表和 CSV。啟用 GitHub Pages 後，可以直接用固定網址查看最新結果，無須下載 Actions 附件。

**一次性啟用設定（須由儲存庫管理員在 GitHub 介面設定）**：

1. 打開本專案 **Settings → Pages**。
2. 在 **Build and deployment** 選擇 **Deploy from a branch**。
3. 選擇 **main** 分支、**/docs** 資料夾，點 **Save**。
4. 部署成功後，公開網站網址通常是 `https://angel92051400-code.github.io/market-breadth-backtest/`，請以 Settings → Pages 顯示的網站網址為準。

**隱私與方案限制**：本儲存庫已設為 Public 且使用 GitHub Pages。公開網站的回測結果與 CSV 可由任何人讀取。

## 策略
- A：市場寬度從 ≤20% 回升到 >20% 買入 10,000 元；上穿 50% 與 60% 各賣出當時持股的 50%。
- B（純費波那契）：僅看加權指數，不讀市場寬度。以過去 120 個**已完成**交易日的高低點計算 38.2%、50%、61.8% 價位；價格由下向上收復其中一個支撐（收盤價距離支撐不超過 +3%）時，隔日買進 0050。從進場訊號當日鎖定下一級較高費波那契價位作停利、支撐下方 3% 作失效出場；條件成立隔日開盤賣出。風控判斷使用加權指數，交易標的是 0050。
- C（綜合策略）：A 的回升訊號發生後 5 個交易日內，且加權指數接近 38.2%、50%、61.8% 任一回撤價位 ±3%，隔日進場；當市場寬度上穿 50% 或 60% 時各減碼 50%。
- 進出場訊號皆於收盤後確認，在下一個共同交易日開盤執行；不使用未來高低點。

## 完整歷史回測及波段變體

從市場寬度網站提供的**最早交易日**開始算到最新一天，並不是只測一筆交易。目前來源始於 **2024-11-11**，有約 486 個交易日。要分析更早年份，需要先取得可靠的歷史市場寬度資料，不能拿當前成分股名單假造；純費波那契需要先累積120個已完成交易日。

保留原始 A／B／C 作為基準，再另加三種事先明確定義的探索性波段策略：

- **A2（純市場寬度波段）**：上穿40%買進；寬度低於40%、上穿50/60%或持有30個共同交易日減碼。
- **B2（純費波那契反彈）**：下跌一天後收漲，且指數在任一費波那契支撐的0～3%上方買進；回落最高指數收盤6%、失守進場支撐3%或持有45日賣出。完全不使用市場寬度。
- **C2（寬度＋費波那契波段）**：寬度上穿40%且加權指數高於Fib50%買進；寬度低於40%、失守Fib50%或持有45日賣出。

各策略每次買賣均以訊號**隔日0050開盤**成交，全額投資、可重複交易，包含買賣費用。停損是收盤後訊號，並非盤中保證成交。報告增加持倉比例及各策略獨立交易明細。

新增策略是在看到原版交易過少後提出，因此**屬探索性回測，不能視為獨立樣本外驗證**。不以交易筆數或績效高低直接挑選最佳策略。歷史前640大成分股存在存活者偏差。

## 手動回測操作

已取消所有每小時／每週自動排程及程式更新自動回測。僅使用 GitHub Actions 的 Run workflow 手動更新網站。瀏覽器 Command+R 只刷新已發布網頁。
## 純費波那契基準策略的限制

B 的入場必須從下方重新站上過去 120 個已完成交易日形成的費波那契支撐，且價格在該線上方 3% 內；出場依進場訊號時鎖定的下一級價位或支撐下方 3%。其交易次數可能很少、空手期間較長；請不要單用總報酬或勝率判斷策略優劣，並與相同期間的 0050 持有比較。

## 使用方式
1. GitHub Actions → Manual Strategy Backtest → Run workflow。
2. 輸入買進／賣出市場寬度門檻（預設 20／70）。
3. 完成後下載 Actions 的 `strategy-backtest-report`，打開 `report.html`。
4. 下載包包含 `summary.csv`、`summary.json`、各策略 `trades_*.csv`、`equity_*.csv` 與 `signal_diagnostics.csv`。

本機：
```bash
python -m pip install -r requirements.txt
python -m pytest -q
python run_backtest.py --buy 20 --sell 50
```

## 研究限制
- 使用當前市值前 640 大回推歷史，**存在歷史成分股前視偏差與存活者偏差**。
- 2025 年資料若未修復，覆蓋率 <95% 的交易日不允許產生訊號；此段不能用插值製造訊號。
- Yahoo 調整後價格是含配息／拆分的績效代理，不是可實際成交的原始開盤價。
- 未平倉不計入勝率，並以同期間 ETF Buy & Hold 比較。
- 樣本期間短／交易筆數少，統計結果不代表策略有預測能力。
- 只有手動 Run workflow 會執行回測，並更新 A/B/C/A2/B2/C2 網站比較。
